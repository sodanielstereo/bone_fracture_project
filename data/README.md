# Dataset

Este directorio está destinado a almacenar localmente el conjunto de datos utilizado en el proyecto.
## Bone Fracture Multi-Region X-ray Data

El proyecto utiliza el dataset **Bone Fracture Multi-Region X-ray Data**, compuesto por imágenes de rayos X de diferentes regiones del cuerpo clasificadas en dos categorías:

- Fracture
- No Fracture

El conjunto de datos contiene aproximadamente 9.246 imágenes.

Fuente:

https://www.kaggle.com/datasets/bmadushanirodrigo/fracture-multi-region-x-ray-data

## Descarga

Cada integrante descarga el dataset desde Kaggle y puede ubicar sus archivos dentro de este directorio.

```text
data/
├── README.md
└── fracture_dataset/
```
